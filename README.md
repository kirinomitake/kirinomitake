### 🚀 QA Case Study: Technical Analysis & Testing

As part of my work on various projects (Idle, Strategy, MOBA), I apply a systematic approach to defect discovery, focusing on logic stability and integrations.

* **App Lifecycle & State Management:** In-depth testing of application states during interruptions (minimizing, loss of focus). Identification of critical synchronization errors in game timers and audio managers.
* **Logic & State Machines:** Analysis of state transitions to prevent soft-locks. Identification of errors in logical flags that block game progression.
* **API Integration Testing:** Using **Postman** and **Charles Proxy** to validate client-server interaction. Monitoring the integrity of JSON responses and preventing errors in the game economy.
* **Interface Adaptability:** Testing **Unity UI (Canvas)** systems. Verification of anchors and layout correctness on devices with various aspect ratios.
* **Backend & Data Validation:** Verifying the accuracy of displayed data through direct database queries using **SQL**.
